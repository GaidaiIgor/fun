OBJECTIVE
Destroy all surveillance nodes (@) within the allotted turns using a limited supply of fork-bombs.

GRID
The game takes place on a rectangular grid of width x height cells, supplied as height rows of width characters each.
Cells: . = empty; @ = surveillance node; # = indestructible passive node.
Coordinates (x, y) start at (0, 0) in the upper-left corner; x increases rightward and y downward.

RULES
Each turn, place one bomb on an empty cell (.) or output WAIT.
Some surveillance nodes move one cell horizontally or vertically per turn, reversing direction at a passive node (#) or grid edge.
A bomb placed on turn t explodes on turn t+2 (the third turn, counting placement as turn 1).
The blast covers the bomb's cell and up to 3 cells in each of the four cardinal directions, stopping at passive nodes (#).
Blasts destroy surveillance nodes (@) and immediately trigger other bombs they reach.
All surveillance nodes must be destroyed before the turns run out.

INITIALIZATION INPUT
Line 1: width height (2 integers): grid dimensions.

INPUT EACH TURN
Line 1: rounds bombs (2 integers): remaining turns and unused bombs.
Next height lines: mapRow (string of length width): the current grid, top row first.

OUTPUT EACH TURN
One line: WAIT, or x y (2 integers) specifying the empty cell on which to place a bomb.

NUMERIC CONSTRAINTS
2 < width, height < 20
3 < rounds < 20
0 < bombs < 10
0 <= x < width
0 <= y < height
Time per turn: 100 ms
First-turn allowance: typically 1000 ms on CodinGame; not explicitly specified for this puzzle.
